# H-Player v1.0.0

H-Player（**H**ighlight **Player**）是一款 Android 端的 B 站集锦 / 高光片段播放器：把一条 B 站视频按「评论区时间戳」或手动输入的时间点拆成多个片段，自动连播、跳过无关内容，并支持横屏 / 全屏沉浸式观看。

## 主要功能

- **一键解析**：从系统分享或粘贴 B 站视频链接（支持 `bilibili.com`、`b23.tv` 短链、BV/av 号），自动解析出视频流与时间轴。
- **片段剪辑**：自动扫描评论区时间戳生成片段列表；也支持手动输入 `0:00:20 6s A` 格式快速编排。
- **自动连播**：段末自动切到下一段并提前预热，切换无加载圈、不卡顿。
- **沉浸式播放**：全屏常驻进度条，双击快进 / 快退，亮度 / 音量手势调节，防误触锁定。
- **画面优先布局**：移除顶部多余栏，播放按钮与时间轴合并为一条控制条；片段列表与评论时间戳合并为可收起面板（支持内嵌 / 右侧浮窗两种形态）。
- **应用内更新**：设置 → 关于 → 检查更新，直接从 GitHub Releases 下载并安装最新版。

## 安装 / 升级

1. 在本页下载 `H-Player.apk`。
2. Android 8 及以上：在系统设置中允许本应用「安装未知应用」。
3. 点击 APK 按提示完成安装；已安装旧版本会直接覆盖升级（同一签名）。

## 已知问题 / 注意事项

- 需要联网；解析依赖 B 站接口，弱网环境下首次连接可能稍慢（已做连接预热与重试）。
- 真机适配主要在 Android 9（Galaxy Note8）与 Android 16（OPPO 折叠屏）上进行。

## 校验

- APK 使用项目私有签名（keystore 别名 `bilihl`），同一签名保证后续版本可覆盖升级。
